# 单位科技索引

[English](unit_techs.md)

[TOC]

本文包含 build `1.11.1.2.2227` 的 32 张普通单位卡所引用的全部 233 项单位
科技。名称和效果来自游戏官方 English 与简体中文本地化，序列化描述参数已展开。

布局或状态在 `techs` 中按单位列出这些科技，名字取自
[`config/names.yaml`](../../config/names.yaml)，本表列出名字对应的 ID。ID 的最后两位
十进制数字编码所属普通单位 ID。`apply_layout` 按 ID 升序添加并激活每项科技，
然后回读激活状态。`基础补给` 是
普通对局的基础价格；试验场测试动作不会把该价格纳入布局模式。
