# 装备索引

[English](equipment.md)

本索引固定对应游戏 build 2227，包含 18 项普通增援装备，以及“增幅专家”开局
内置的次级增幅核心。名称和效果来自该版本的 `EquipmentGroupData`；除非效果中
另有说明，下列百分比均为游戏原生的加法修正值。

| 装备 ID | 名称 | 效果 |
| --- | --- | --- |
| 1305003 | 光子涂层 | 开战后的 30 秒内受到的伤害降低 30%，并免疫电磁、引燃、酸液和退化光束效果 |
| 1306001 | 坦克生产线 | 仅巨型单位可装备；每 13 秒生产 2 辆铁锤坦克，共生产 7 次 |
| 1306002 | 野马生产线 | 仅巨型单位可装备；每 11 秒生产 4 个野马，共生产 8 次 |
| 1306003 | 钢球生产线 | 仅巨型单位可装备；每 16 秒生产 2 个钢球，共生产 6 次 |
| 1307001 | 保护屏障 | 仅地面巨型单位可装备；生成一个 60000 生命值的防御屏障保护周围单位 |
| 1308001 | 抗干扰模块 | 免疫电磁干扰、骇客控制以及核心建筑爆炸造成的瘫痪效果 |
| 1309001 | 汲取模块 | 生命值增加 30%，并将造成伤害的 90% 转化为自身生命值 |
| 13010001 | 便携式护盾 | 获得能量护盾；护盾值等于单位生命值，并且至少能够阻挡一次伤害 |
| 13020001 | 纳米维修包 | 每秒恢复最大生命值的 4.5% |
| 13030001 | 激光瞄具 | 射程增加 20 米；仅适用于运行时判定为远程的单位 |
| 13030002 | 重型装甲 | 生命值增加 75% |
| 13030003 | 改良火控系统 | 攻击力增加 65% |
| 13030004 | 强化模块 | 攻击力增加 25%，生命值增加 25%，每次升级消耗的补给减少 100 |
| 13030005 | 速攻模块 | 移动速度增加 5，攻击力增加 35% |
| 13030006 | 超重型装甲 | 生命值增加 150% |
| 13030007 | 增幅核心 | 攻击力增加 50%，生命值增加 50% |
| 13030009 | 次级增幅核心 | 攻击力增加 22%，生命值增加 22% |
| 13030010 | 统御核心 | 攻击力增加 50%，生命值增加 100%，每回合开始时获得 50 补给；若装备单位在战斗中被消灭，己方全部单位同时死亡 |
| 13040001 | 部署模块 | 装备单位每回合都可以在部署阶段自由移动 |

布局格式在单位的 `equipment` 字段中填写数字装备 ID；本索引不引入新的布局
结构。执行器不会扣除增援卡牌的获取费用，而是通过 `MAD_AddEquipment` 在当前
一方的试验场库存中创建一件装备，再由原生 `CanUseEquipment` 检查装备能力、
唯一装备槽是否为空、所有权以及效果对目标的限制。

在 build 2227 中，战争工厂、深渊和巨山不能使用任何装备。上述 19 项装备的
配置持续回合数均为无限；只有统御核心会改变每回合获得的补给。
