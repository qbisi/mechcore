# Mechcore Wiki

A player- and agent-facing guide to **Mechabellum**, grounded in the native game
build and extracted configuration tables of this repository.

Every article explains observable game behavior, the consequences of player
decisions, and the exceptions that matter in play, within an explicit scope.

## Getting Started

- **[How a Match Works](how-a-match-works.md)** — Start from how a match is won
  and how surviving mechs damage the opponent's reactor core, then trace
  backward through automated combat, pre-battle deployment decisions, supply and
  reinforcements, and what carries over into the next round.

## How This Wiki Is Organized

| Section | Focus |
| --- | --- |
| **Getting Started** | How a standard 1v1 match unfolds from victory condition and combat settlement back to deployment decisions and economy |
| **Game Mechanics** | Canonical rules for deployment mobility, experience and leveling, reactor core settlement, supply, reinforcements, towers, and combat |
| **Game Encyclopedia** | Units, technologies, officers, equipment, commander skills, blueprints, energy tower skills, contraptions, and constructions |
| **FAQ** | Direct answers to common player questions linking back to canonical mechanics |

## Scope and Authority

- **Native game authority:** Claims describe the native game on the repository's
  pinned game version, not simulator implementation status.
- **Standard 1v1 baseline:** Unless a page states otherwise, rules and numbers
  apply to standard 1v1 versus matches with no extra game rules enabled.
- **Verified values:** Numerical figures trace to the repository's extracted
  configuration tables rather than unverified community estimates.
