# Projectile

How a projectile leaves its weapon, climbs and flies, and what its skill does
while a burst is still releasing.
[`combat.md`](../../docs/rules/combat.md) states the rules.

Each fight is its layout fought once in the game, read back as a fight. A
projectile's `position` on each tick after its `projectile_released` is how it
climbed and flew.
