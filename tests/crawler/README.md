# Crawler

The Crawler's standard fights: the six
[standard layouts](../README.md#standard-unit-layouts) under seeds 4242 and
1787720817, 10 fight documents in `fights/`, each named for its layout and
seed. CI verifies them; `mechcore verify --backend game
tests/crawler/fights/*.yaml` records them again where the game runs.

The Crawler has no M3: it is its own opponent there.
