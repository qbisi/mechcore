# Phantom Ray

The Phantom Ray's standard fights: the six
[standard layouts](../README.md#standard-unit-layouts) under seeds 4242 and
1787720817, 12 fight documents in `fights/`, each named for its layout and
seed. CI verifies them; `scripts/record-fights.py --check
tests/phantom_ray/fights/*.yaml` records them again where the game runs.

The Phantom Ray's M3 with seed 4242, recorded with the `target_refs`
channel, showed three Phantom Rays still cooling, and still naming the dead
last Crawler, for the five ticks the fight runs on after it is won.
