# Disabled technologies

What a buff that disables technology switches off on a unit while it runs,
and what it gives back as it leaves. [`technology_effects.md`](../../docs/rules/technology_effects.md)
states the rule. Each fight strikes units with an Electromagnetic Impact or
Electromagnetic Barrage's shells and reads, in each unit's corrections and
derived numbers, the tick the technologies go and the tick they come back.
