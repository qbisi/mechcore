# Maintenance array

Whom a repair technology's unit repairs about it, how often, from when, and
what a buff that disables technology, a travel and a rebirth do to its count.
[`technology_effects.md`](../../docs/rules/technology_effects.md#repair-technologies)
states the rule. Each fight is its layout fought once in the game, read back
as a fight; the repairs show as healing events.
