# Dead summons

What a technology makes its unit summon where it dies.
[`technology_effects.md`](../../docs/rules/technology_effects.md#summons-where-a-unit-dies)
is the rule. Each fight puts the technology on a unit the other side kills:
Mechanical Division on blue's Steel Balls, which leave Crawlers. A buff that
summons where its unit dies, Replicate's, is
[`technology_buff/`](../technology_buff/README.md)'s.

A recording holds each summon's `unit_created` event, where it stood and its
formation, and the units table every tick after.
