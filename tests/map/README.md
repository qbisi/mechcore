# Map fixtures

What a map's neutral crystals do to a fight.
[`map.md`](../../docs/rules/map.md) is the rule. Each fight here is a fight
pinned elsewhere under `tests/`, recorded on Desert, map 1001, whose crystals
of collider priority 3 change it; its comment names the fight and how long it
ran on the Training Ground. A fight made for a rule of the map's own says in
its comment what it measures. A map whose crystals change no fight, Grass,
has none here.
