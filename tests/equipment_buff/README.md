# Equipment buffs

What a buff item adds to the unit wearing it, and which buffs it keeps off
that unit. [`equipment_effects.md`](../../docs/rules/equipment_effects.md#buff-items)
is the rule. Each fight puts one item on one formation and changes nothing
else from a control it names: when the item's buff is added and to whom, what
it writes, and the buffs it keeps off: Photon Coating's invincibility and
Anti-Interference Module's ignored group, each against an Electromagnetic
Impact, and the module against a tower's loss.
