# Fire technologies

Where a fire technology's unit leaves fires as its main skill hits, and how
wide and long they burn. [`technology_effects.md`](../../docs/rules/technology_effects.md#fire-technologies)
states the rule, and [`terrain.md`](../../docs/rules/terrain.md) how a fire
burns. Each fight is its layout fought once in the game, read back as a
fight; a fire is a `terrain_created` event and its hits `damage` with no
projectile and no source unit.
