# Wreckage detonation

Which units a kill-explosion technology's unit's hits set off, whom each
explosion strikes, and what a buff that disables technology does to it.
[`technology_effects.md`](../../docs/rules/technology_effects.md#kill-explosion-technologies)
states the rule. Each fight is its layout fought once in the game, read back
as a fight; the explosions show as damage that names the unit and no skill.
