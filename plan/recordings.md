# 录像成为可分析的对象

一份录像直接读出谁在哪个 tick 用哪个技能对谁造成多少伤害、谁杀了谁、经验怎么分，读得到战斗的
内部过程，agent 只用 `mechcore` 就能对整个语料统计。

研究一直卡在"录不到"，而不是"查不动"。录像之外的观测只有 instrument sidecar：每个新问题要
一个新 profile，profile 互斥，同一场仗换 profile 录好几遍；观测先进 sidecar、再升格进格式，
每次升格进录像都要重录全部钉子；谁打了谁、哪个技能造成的伤害、谁杀了谁、经验、buff
的施加与到期，都不在录像里。把录像做成 agent 能直接统计的对象，也是找战斗奖励信号的前提。

- **instrument 是 MCFR 的成员。** 按通道组织，每个通道一张有类型的 parquet 表，不进哈希；通道可以任意组合，一场仗录一次；边打边写，不攒到战斗结束；模拟器写同样
  的通道，游戏与模拟器的内部过程因此能逐 tick 对照。
- **instrument 的量不超过实体数的线性倍。** 两两配对的数据不录，只录每个实体有上界的那部分。
  RVO 一次求解只看 agent 自己的邻居列表，上界是 `maxNeighbours`：每个 agent 一行求解（输入、
  两条梯度追踪、起决定作用的那个 VO、输出），加至多 `maxNeighbours` 行邻居，完整 VO 几何放在
  开关后面。选择器录选中的目标与前几名候选。
- **伤害、击杀和经验读游戏自己的，进录像。** 游戏在逻辑 tick 里按编队累加造成的伤害、
  实际扣掉的生命、击杀和承受的伤害（`BattleStatisticManager`），编队经验由 `ExpSystem` 分配；
  两者都进录像的哈希，模拟器照样复现。每一下伤害是哪个技能、哪颗投射物打的，这些计数里没有，
  仍由伤害事件带着。
- **查询用 SQL，可推导的量不进文件。** `mechcore query` 把录像的成员按一条规则展开成关系表，
  在二进制自带的 SQLite 里跑 SQL，按需解码，按录像内容缓存；挂几份录像就能在一条查询里对照。
  每回合摘要、每单位汇总、双方随时间的序列是查询的答案，写成查询，存进文件只会在口径变时过期；
  录像只存 build 持有的东西，build 自己维护的计数照录。
- **模型按需改，改了就重录。** 录像的内容一变，全部钉子在有游戏的机器上重录。

## 栈

1. **规格里过期的三处。** `docs/spec/mcfr/mcfr.md` 说 `unit_created` 没有夹具（召唤的夹具已钉住
   它）、钉住的 buff 只有塔被摧毁写下的（电磁冲击的也钉住了）、被过滤的回血是"超级部署落地的补满"
   （实际是旅行途中每秒一次的回血）。

## 停车场

- **逐个机制核对入口方法记下的事件。** 单位生成、治疗、buff 施加与移除、护盾和地形的移除原因，
  都在 build 的入口方法上记录，没有为每种召唤、回血、buff 或移除找夹具；钉住的对局见过塔被摧毁和
  电磁冲击写下的 buff、召唤的 `unit_created`、伤害打空的护盾和回合结束移除的地形，没见过
  `healing` 和地形的其它移除原因。reopen_when：研究某个召唤、回血、buff 或移除机制时，它的录像里
  对应事件缺失、多出，或原因与 build 的本意不符。

- **机制状态的空白。** 录像没记旅行状态（`IsSuperDeployment`，单位上的一个布尔字段，只动旅行的
  夹具）、战场技能的落地（下落中的子效果和落地的 tick，一个新事件，只动有战场技能的夹具）、
  场上的导弹（不是 `FightCrystal`，要一张空时不写的新表，否则全部哈希都动）和移动行为（信标给了
  谁、走到第几段）。模拟器在这些地方出错，哈希抓不到，或者只能从很多 tick 之后的位置反推。
  reopen_when：换版本的全量重录开始，搭它一起录；或广度的战场技能、地形节点有一场分叉因此定位不了。

- **模拟器写 instrument 通道。** RVO 求解与目标搜索由模拟器写成同样的行，游戏与模拟器的内部过程
  逐 tick 对照。reopen_when：单位 lane 的一个研究卡在 RVO 或选目标的分歧上，而逐 tick 的状态
  对照定位不到是哪一步。

- **实体表。** 每个实体不变的字段从逐 tick 表挪到一张"变化才记一行"的实体表，读取时按 tick
  合并回完整状态。它省下的比存储一步的其余几项小一个量级，而 `team_id`、`domain` 会被精神控制、
  钻地改变，读写两端都要处理变化。reopen_when：录像体积成了语料同步或分析的瓶颈。
